# Adding data

- Before running multisquadTestData.sql delete the existing 9Tap database if there is one
- Run Update-Database in the Package Manager Console to recreate the database
- Double-click on multisquadTestData.sql to open it in Visual Studio
- Connect to the 9Tap database
- Run the script

**Note**: The 9Tap database is named "NineTapTour.NineTapDb" and should be located
in (localdb)\MSSQLLocalDB
